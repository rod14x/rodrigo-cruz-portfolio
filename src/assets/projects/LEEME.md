# Capturas de proyectos

Una imagen por proyecto (`.webp`, `.jpg` o `.png`, idealmente 1280×800, proporción 16:10).
El nombre del archivo debe coincidir con el campo `image` del proyecto en `src/content.js`.

Con los datos de ejemplo serían:

- `proyecto-uno.webp`
- `proyecto-dos.webp`
- `proyecto-tres.webp`

Si falta una imagen, la tarjeta muestra una ilustración de código, así que la web funciona igual.
